PORTFOLIO VIDEOS
================

The site plays the files in THIS folder:

  clip-1.mp4 ... clip-7.mp4   (web-optimised videos)
  clip-1.jpg ... clip-7.jpg   (poster / thumbnail for each video)

These were generated automatically from the original phone clips in the
../video folder (H.264 MP4, so they play in every browser incl. Chrome).

To CHANGE or ADD videos
-----------------------
1. Put your new clips (.mp4 or .mov) in the ../video folder.
2. Double-click ../convert.bat  (it rebuilds this folder automatically).
   - It overwrites clip-1..N in order, so arrange/rename source files as needed.
3. If you add MORE than 7 clips, also add matching lines in
   assets/js/portfolio.js (the CLIPS list).

To REORDER
----------
Rename the mp4/jpg pairs (clip-1 shows first, clip-2 second, etc.).
